# 📌 Herança em Java

Repositório com exercícios e exemplos que fiz para entender herança na prática durante meus estudos, incluindo conteúdos da faculdade e algumas práticas mais recentes.

## 💻 O que tem aqui
- Classes e subclasses
- Reutilização de código
- Conceitos de POO
- Exemplos práticos

## 🛠️ Tecnologias
- Java

## 🎯 Objetivo
Entender na prática como funciona herança e melhorar a organização do código usando orientação a objetos.

## 📈 Sobre
Aqui tem desde exercícios mais básicos até exemplos um pouco mais estruturados, acompanhando minha evolução no uso de POO.
